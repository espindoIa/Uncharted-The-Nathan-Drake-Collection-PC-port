On 0.2.3 or older? The launcher offers this update: press **UPDATE TO 0.3.0** next to PLAY.

## Fixed

- **Random crashes after a while ("exit code 3")** (#30, #24, #27). GPU results reach the game's
  memory a little late; when the game had reused that memory in between (an area unloading, a
  cutscene starting), the late copy overwrote it and the game crashed later. That can no longer
  happen.
- **Crash after a long session in Uncharted 2**, and a **freeze inside the port's fault handling**.
- **Graphics cards with 6-8 GB**: no more texture thrashing (hitches, and the crashes in #24).
- **Uncharted 3: blurry view when aiming** (#16).
- **Ultrawide (21:9 / 32:9) now shows more at the sides** instead of cutting the top and bottom (#20).
- **Fewer shader hitches**: compute shaders are compiled in the background before they are needed.
- **Update 1.02 from exFAT/FAT32 drives** (USB sticks), **"Error 1450" with 16 GB of RAM**, AMD and
  RTX laptop hitches, Uncharted 3 level-start freeze (work from a ROG Zephyrus G14 laptop).

## New

- **Cheats** (#26): the launcher's new **Cheats** tab: Invincible, Infinite ammo, No reload,
  Infinite grenades, One-hit kills (needs update 1.02).
- **Start a game directly** (#25): Launcher -> Advanced -> **Game shortcuts**, or double-click a
  game's card.
- **Launcher**: easier to use, a "Recommended" preset for your graphics card, hidden buttons fixed.
- **Crash messages say what crashed**, and a **freeze report** is saved when a game stops showing
  frames for 30 seconds. Please attach `boot.log` (and the `hang-*.txt`) to a GitHub issue.
- A warning when update 1.02 is missing: most fixes need it.

See [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`). Recommended: update 1.02 next to it, named like it plus `-patch`.
3. Pick a game and a preset and press **PLAY**.

> **No game files are included.** You need your own dump of the Collection (CUSA02344). Not
