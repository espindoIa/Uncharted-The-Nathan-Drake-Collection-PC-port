**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

On 0.2.2 or older? The launcher offers this update: press **UPDATE TO 0.2.3** next to PLAY.

## Fixed

- **Uncharted 1: guns flickering flat grey** (#23). With multithreaded rendering on, Nate's rifle and
  pistol (and at times other objects) were drawn flat grey on some frames. Drake's Fortune now always
  runs without multithreaded rendering; it gave no extra speed there.
- **Uncharted 2 crash `ASSERTION: m_lookAt.X() == m_lookAt.X()`** (#24). The point Nate looks at could
  become invalid and the game stopped. It now resets that point instead, like the Uncharted 3 fix
  from 0.2.0.

Also in 0.2.2 (if you skipped it): the Windows 10 start-up crash in all three games (#22), the
Uncharted 3 Syria crash (#21), all 22 languages and **Unlock all chapters** (launcher -> Advanced).

## Known issue

- **Ultrawide (21:9 / 32:9) cuts off the top and bottom** instead of showing more at the sides (#20).
  A fix is in progress; until then, 16:9 shows the full view.

See [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`). Recommended: update 1.02 next to it, named like it plus `-patch`.
3. Pick a game and a preset and press **PLAY**.

> **No game files are included.** You need your own dump of the Collection (CUSA02344). Not
> affiliated with Sony, Naughty Dog or Bluepoint Games.
