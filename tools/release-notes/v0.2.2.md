**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

On 0.2.1 or older? The launcher offers this update: press **UPDATE TO 0.2.2** next to PLAY.

## Fixed

- **Windows 10: all three games crashed right at start on some PCs** (#22). The games run their job
  code on PS4 fibers, small stacks in the game's own memory. Some Windows 10 builds ended the game
  whenever it continued after an exception on such a stack. The port now tells Windows which stack
  is in use first.
- **Uncharted 3 crash in the Syria chapter** (#21, `PatchImageSharp: Assertion Failed`). A damaged
  image description during a level load stopped the game; that one write is now skipped.
- **Launcher errors are no longer silent.** If the launcher can't start, it now shows the error and
  saves it to `analysis\uncharted-user\launcher-error.log`; please attach that file to an issue.
- **Long sessions:** a diagnostics list grew with every GPU image and buffer the game made; it is
  now only kept when GPU fault diagnostics are switched on.

## New

- **All of the Collection's languages.** Launcher -> Advanced -> **Language**: pick any of the 22
  languages the games have text for. Each game's main menu then offers it next to English: press
  **Square** there to switch menus and subtitles. Spoken language depends on your copy of the game;
  the list marks the languages yours has voices for.
- **Unlock all chapters.** Launcher -> Advanced -> **Unlock all chapters**: every chapter in all
  three games' Chapters menu, plus the Brutal difficulty, without finishing the games first. Your
  saves and progress are untouched. Off by default; needs update 1.02.

## Known issue

- **Ultrawide (21:9 / 32:9) cuts off the top and bottom** instead of showing more at the sides (#20).
  A fix is in progress; until then, 16:9 shows the full view.

Everything else is as in 0.2.1: see [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`). Recommended: update 1.02 next to it, named like it plus `-patch`.
3. Pick a game and a preset and press **PLAY**.

> **No game files are included.** You need your own dump of the Collection (CUSA02344). Not
