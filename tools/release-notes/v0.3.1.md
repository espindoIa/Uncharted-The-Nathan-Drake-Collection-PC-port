On 0.3.0 or older? The launcher offers this update: press **UPDATE TO 0.3.1** next to PLAY.

## Fixed

- **Sun shadows no longer flicker** with TAA, FSR or DLSS/DLAA.
- **Steadier anti-aliasing**: the port started each frame twice, which threw away the
  anti-aliasing's history every frame (shimmering edges). Now it starts once per frame.
- **AMD Radeon RX 9070 XT: games stopped at start** with "Failed to create graphics pipeline"
  (#40). A pipeline the driver refuses is now created again without the pipeline cache; if it is
  still refused, only the draws that need it are skipped. Not tested on that card yet: please
  report how it goes.
- **Steam Deck and other Linux AMD/Intel graphics**: GPU memory binding and large texture
  conversions now stay within what those GPUs support.
- **Desktop shortcut and Game shortcuts with a moved Desktop** (OneDrive, redirected) (#39).
- **"exception 0x20474343" now says what failed** (#47), for example running out of memory.

## New

- **Choose your game update in the launcher** (#32): Advanced -> **GAME UPDATE** -> **Choose
  update folder** (wherever your extracted update 1.02 is), or **Install from .pkg**. The update
  is checked first, and a damaged one is named before the game starts.
- **Steam Deck** (by kuraeow, #35-#38): 16:10 (1280x800), movies keep their shape at 16:10 and
  ultrawide, update 1.02 merged into the game folder is recognised, and one set of launcher
  options for every Steam shortcut under Proton.

The shadow and anti-aliasing fixes are ported from SuperMedo's Uncharted port (kj2223), and the
Steam Deck graphics fixes too (hugouchoasborges). Thank you!

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`). Recommended: update 1.02 next to it, named like it plus `-patch`,
   or chosen in Advanced -> GAME UPDATE.
3. Pick a game and a preset and press **PLAY**.

> **No game files are included.** You need your own dump of the Collection. Not affiliated with
> Sony, Naughty Dog or Bluepoint Games.
