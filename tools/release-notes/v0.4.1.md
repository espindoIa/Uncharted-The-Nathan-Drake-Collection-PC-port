On 0.4.0 or older? The launcher offers this update: press **UPDATE TO 0.4.1** next to PLAY.

A small update with two crash fixes.

## Fixed

- **Drake's Fortune: crash after about an hour ("out of device memory")** (#63). The game
  handed the port a render target described by garbage data (a 960x540 image with 6,772 layers,
  16 GB); creating it took all video memory. Impossible images like that are now skipped.
- **Uncharted 2: crash in the port's own code** (#56). A texture sampler asked for a custom
  border color from a table the game had not set; it is now read safely.

Everything in 0.4.0 (real upscaling with DLSS / FSR, no more freeze before cutscenes, the
grenade launcher fix, ...) is of course included. See
[CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **US version (CUSA02320) with update 1.02 stops at start for some players** (#29, #43).
  Being looked at; renaming the update folder (`...-patch`) starts the games as 1.00 meanwhile.
- **Uncharted 1 can crash in the first levels** (#42, #62). Being looked at.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.
